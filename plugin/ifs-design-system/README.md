# ifs-design-system plugin

- **ifs-prototype**: describe a screen or flow, answer a few questions, approve a plain-language layout, and get a clickable single-file HTML prototype built from the IFS DS kit.

The kit is fetched from GitHub Pages each time, so prototypes always use the latest components. Browse them in Storybook: https://shinyc01.github.io/new-cl-design-system/ifs-kit/dist/storybook/

Needs: Claude Code, internet access, and optionally Google Chrome (for the skill's self-check screenshots).
