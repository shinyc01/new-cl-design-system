# IFS DS code kit — conventions

The kit is the code twin of the Figma file **IFS Design System** (`atgUmwcA1AE5sjFoWBT7ar`). Every component here must match its Figma component exactly. Never invent a component that Figma doesn't have.

## Layout
```
src/tokens.css            exported Figma variables (dark mode) + text-style (.t-*) and effect-style (.fx-*) classes
src/icons.js              window.IFS_ICONS — SVG inner markup per icon per size, exported from Figma
src/components/<family>.css + <family>.jsx   one pair per Figma component family (ES modules)
src/components/index.js   kit entry: imports every family, its CSS, tokens and icons
src/components/registry.js the shared IFS object every family registers into
src/gallery/<family>.jsx  variant grids (every variant + state) — the source for Storybook stories
src/stories/              GENERATED by tools/gen-stories.mjs (npm run stories) — don't edit
src/docs/*.mdx            hand-written Storybook pages
build.mjs                 esbuild → dist/ifs-ds.js (window.IFS) + dist/ifs-ds.css; `inline` makes single-file prototypes
tools/extract-spec.js     read-only use_figma script that returns exact specs with token names
tools/shot.sh             headless-Chrome screenshot of an HTML file (prototype self-checks)
```
Commands: `npm run storybook` (review, http://localhost:6006) · `npm run build-storybook` (static site in dist/storybook) · `node build.mjs`.

## Getting specs (exact, not guessed)
Run `tools/extract-spec.js` via `use_figma` on the component set: it returns padding, gap, radius, sizes, and the **variable name** bound to each fill/stroke/text. Variable `a/b/c` is CSS `var(--a-b-c)` (lowercase; spaces, `/` and `,` become `-`; parentheses dropped). If a fill is raw hex (no variable), use the hex. Use `get_screenshot` on a variant to see the target. Don't use `get_design_context` code as the implementation.

## CSS rules
- Class names: `.ifs-<component>` block, `--<modifier>` for Figma variant values: `.ifs-button.ifs-button--primary.ifs-button--m`.
- Only token vars for colour, spacing, radius, type. Raw values only where Figma itself has no variable (comment `/* raw in Figma */`).
- Typography: apply the Figma text style's values from tokens.css `.t-*` (copy the font shorthand + letter-spacing into the component rule).
- Strokes keep the Figma box size: `INSIDE` stroke → `box-shadow: inset 0 0 0 Wpx color`; `OUTSIDE` → `box-shadow: 0 0 0 Wpx color`; `CENTER` → `outline: Wpx solid; outline-offset: -W/2px`. Use `border` only when Figma's stroke changes layout.
- States: Figma `State=Hover/Pressed/Disabled/Focus` → `:hover`, `:active`, `:disabled`/`[aria-disabled=true]`, `:focus-visible`. Also support `[data-state=hover|pressed|focus]` so the gallery can show forced states.
- Focus ring (shared): `box-shadow: 0 0 0 1.5px var(--focus-focus-inner), 0 0 0 3px var(--focus-focus-outer)`.
- Effect style `blur/medium` → `backdrop-filter: blur(var(--blur-medium))`.

## JSX rules
- React 18 function components in ES modules. Each file starts with `import React from 'react'; import { IFS } from './registry.js';`, refers to other kit components as `IFS.Button` (no cross-family imports), and ends with `Object.assign(IFS, { A, B }); export { A, B };`.
- Props mirror Figma component properties in camelCase with lowercase values: `Type=Primary` → `type="primary"`, `Size=M (32)` → `size="m"`, boolean `show-icon-left` + instance swap `Icon left` → `iconLeft="system-heart"` (an icon name; absent = hidden). Text props → `children` or a named prop.
- Interactive components work for real (open/close, select, type) with internal state, and also accept controlled props (`value`/`onChange`, `open`/`onOpenChange`).
- Icons: always `<Icon name="…" size={16} />`. Never draw SVGs inline and never use an icon font.
- The header comment of every component states its Figma name + node id: `// Figma: button (65:3211)`.

## Checking
Add the component's grid to `src/gallery/<family>.jsx`, run `npm run storybook`, and compare its story with the Figma node in the Design tab (or with `get_screenshot` of the same variant). Fix any difference in size, spacing, colour, or type before calling it done.
