# IFS Design System — code kit

Every component here is the code twin of a component in the Figma file **IFS Design System**. Colours, spacing, radius and type come from the Figma variables, and icons are the Figma icons.

## Checking a component against Figma

1. Open a component's **All variants & states** story.
2. Open the **Design** tab in the bottom panel. It shows the matching Figma node next to the code.
3. Compare size, spacing, colour, type and every state. Hover, pressed and focus are forced in the grid so you don't have to interact.

Anything that differs is a kit bug. Note the component and the variant.

## Usage notes

Each component's **Docs** page carries its usage guidance. Lines marked **(Figma)** quote notes written on the Figma canvas. Lines marked **(inferred)** were deduced from names and pattern screens, so check those.

The product-wide rules and the screen anatomy live in `guide/components.md`.
